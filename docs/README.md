# GitHub Pages files

This directory is the document root for the project's GitHub Pages website.

| File or directory | Purpose |
|---|---|
| `index.html` | Main Colorimetry project webpage |
| `.nojekyll` | Tells GitHub Pages to publish the directory without Jekyll processing |
| `assets/colorimetry.css` | Shared stylesheet |
| `assets/images/` | Generated images used by the website |

The webpage links to source code and CMF data through the GitHub repository. Files outside `docs/` are not assumed to be directly published by GitHub Pages.
